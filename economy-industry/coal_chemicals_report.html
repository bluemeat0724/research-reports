00

先放对三把尺子

核心判断 / 以材料工业理解煤化工，而不仅是能源替代

中国煤化工已经是一个国家级的资源转化与材料供给体系。但“绝对量大”“国内占比高”和“能够替代进口能源”，是三件不同的事。

基础原料：国内主导

84%

煤制甲醇占国内甲醇产量约84%；煤制合成氨约占78%。部分原料供给高度依赖煤路线。[1]

资源转化：国家级量级

1.02×

较宽口径转化煤炭的热值，约相当于墨西哥2024年全国能源供应总量。只比较热值，不代表功能替代。[1][4]

替代燃料：国内份额仍小

1.65%

煤制天然气产量约相当于中国全年天然气消费的1.65%；绝对规模与国内份额须分开看。[1][4]

同类用量天然气、含氮量尺度类比重量、投入热值情景换算聚酯、尿素、生活用水

全文使用2024年作为统一对照年；来源可能发表于2025或2026年。原始数值按其来源精度呈现，换算比例适度取整。

03

投入热值，放到国家能源的尺度上

热值类比 / 不是煤化工产品的有用能，也不是能源替代率

合成氨：先统一成“含氮量”，再比较国家

从原料吨数，走到终端材料

情景换算 / 明确原料分配、化学计量和损失假设

下列结果回答“这些原料理论上能配套多大下游产量”，不是对实际终端产出的统计。必须补足其他原料，并区分实际用途与理想计量。原料产量来自行业研究；全球纤维参照来自Textile Exchange。[1][7]

乙二醇 → PET聚酯

03 / UREA

合成氨 → 尿素

9,861 万吨尿素 / 理论配套

全部5588万吨煤制合成氨转向尿素、补足二氧化碳并忽略损失时，理论对应约9861万吨尿素。

不能将尿素吨数再与投入的合成氨吨数相加，作为独立最终产品总量。

2NH₃ + CO₂ → CO(NH₂)₂ + H₂O
5588 × 60 / 34 ≈ 9861 万吨
25.7%是“理论PET配套量 / 全球聚酯纤维产量”的量级对照。不能改写为“中国煤化工实际生产了全球四分之一的涤纶”。它既包含原料用途假设，也跨越了PET总用途与纺织纤维的边界。

绝对规模之外：替代、商业与资源约束

三个不同维度 / 不把产量、营收和耗水拼成同一个“规模”

8.1　煤制油：约等于5天原油进口的重量

2024年煤制油产量752万吨，同年中国原油进口55342万吨，两者重量比约1.36%。按2024年366天平均进口量换算，约相当于4.97天进口重量。[1][3]

752 / 55342 ≈ 1.36%
752 / (55342 / 366) ≈ 4.97 天

煤制产品油与原油的组成、用途和加工环节不同。上述只是重量对照，不是精确原油替代率，也不能推导出炼厂产出等价量。

09

把“大”放回它真正成立的位置

结论与阅读边界

材料和原料，是规模判断的重心。甲醇、合成氨的国内产量份额较高，烯烃与乙二醇已经形成千万或数百万吨级供料能力。煤制油只是其中一条路线。[1]

国家级绝对量，不保证国内高份额。煤制气产量足以和一些国家全年需求相比，却只相当于中国消费的约1.65%；煤制油产量仅相当于中国原油进口重量的约1.36%。[1][4][3]

每一种比较，都有一个不能跨越的边界。热值是资源投入的尺度；吨数是物料的尺度；国内份额是产业依赖的尺度；营业收入与利润是商业尺度。任何单一指标都不能概括全部产业意义。

中国煤化工是一个拥有国家级资源转化规模、在部分基础原料中占据主导地位的材料工业体系；但它并不是一套已经能够全面替代石油与天然气的能源系统。

这是一项基于2024年统一基准的规模判断，不是对2026年实时产能、最新投产项目或未来替代潜力的预测。[1][4][3]
年份一致，版本不必相同

数据年统一为2024；2025或2026出版物可能提供2024年数据。保留原数据包的版本，不混入未经核验的新值。

存量、能力与流量分开

年末产能不能替代全年平均能力；全年产量除以年末产能，不直接标为年度产能利用率。

尺度相当，不是用途可替代

钢铁与甲醇只有重量类比；投入煤炭热值与国家能源供应只有量级可比。

不消除不了解的统计差异

合成氨跨来源总量有冲突；气体标准状态可能不同；用水取耗边界不完整。保留警示，不强行归一。

换一把尺子，亲手比较。

切换国家、产品与假设，观察同一组数据怎样呈现不同规模。
