# web-visualization

可视化实验页面。每个条目都是可直接在浏览器打开的静态 HTML，没有构建步骤。线上地址使用同一相对路径，站点是 https://reports.bluemeat.work/ 。

根目录 `index.html` 的分类首页另行维护，不由本文件更新。

| 页面 | 路径 | 说明 |
|---|---|---|
| iPhone Duo — Two screens. One object. | [iphone-duo/index.html](iphone-duo/index.html) | 双屏折叠概念的交互页面。同目录还有四张预览图。`../iphone_duo.html` 与这份 `index.html` 字节相同，供旧路径使用。 |
| Phone Motion Lab — A visual language for 3D transforms | [phone_motion_lab.html](phone_motion_lab.html) | 3D 变换动效的单文件页面。 |
| 雨夜の街角 — HOSHINO MART | [rainy-night-mart/index.html](rainy-night-mart/index.html) | 雨夜便利店场景。同目录有 `preview.png`。 |
| Three.js 公开作品浏览器 · Agent Visual Atlas | [threejs_agent_gallery.html](threejs_agent_gallery.html) | Three.js 公开效果图浏览器，单文件。 |
| NGC 7741 Meridian — Meridian Observatory | [ngc-7741-meridian/index.html](ngc-7741-meridian/index.html) | 棒旋星系的 Canvas 粒子天空。文件清单、操作和依赖见 [ngc-7741-meridian/README.md](ngc-7741-meridian/README.md)。 |
